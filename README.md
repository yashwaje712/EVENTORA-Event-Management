# EVENTORA — Professional Event Management System

A modern, production-oriented event management starter built with React, TypeScript, Vite, Tailwind CSS, Node.js, Express, and MongoDB-ready architecture.

## Modules
- Public event discovery
- Event details
- Authentication-ready user flows
- Organizer event management
- Admin dashboard
- Attendee/registration management
- Analytics cards
- Responsive professional UI
- API structure ready for backend integration

## Run frontend
```bash
npm install
npm run dev
```

## Project structure
- `frontend/` — React application
- `backend/` — Express API starter
