## 🎯 What is EVENTORA?

EVENTORA is a professional event management system concept built to simplify the complete event lifecycle — from discovering an event to registration, ticketing, attendee management, analytics, and organizer operations.

It is structured like a real-world product rather than a basic CRUD college project.

### ✨ Core Experience

| Area | Highlights |
| --- | --- |
| 🎟️ **Event Discovery** | Search, categories, featured events & event cards |
| 👤 **User Experience** | Clean attendee-focused interface and registration flow |
| 🏢 **Organizer Workspace** | Create, manage and monitor events |
| 🛡️ **Admin Control** | Platform-level management & analytics |
| 📊 **Analytics** | Registrations, revenue, attendance & satisfaction metrics |
| 📱 **Responsive UI** | Desktop, tablet and mobile friendly |
| 🔐 **Security Ready** | JWT authentication & role-based access architecture |
| 💳 **Payments Ready** | Designed for future ticket payment integration |

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yashwaje712/EVENTORA-Event-Management.git
cd EVENTORA-Event-Management
```

### 2. Start the frontend

```bash
cd frontend
npm install
npm run dev
```

### 3. Start the backend

Open another terminal:

```bash
cd backend
npm install
npm run dev
```
